# Data Directory

Este directorio contiene los conjuntos de datos originales utilizados en el proyecto.

## Descripción

Los datos originales sin procesar deben colocarse aquí antes de ejecutar los notebooks de análisis. Estos datos incluyen:

- Máscaras por cultivo
- Variables climáticas (ASAP/ASIS)
- Producción (FAOSTAT)
- Clasificación climática Köppen

## Uso

1. Coloque los archivos de datos originales en este directorio
2. Ejecute `datos.ipynb` para realizar el análisis exploratorio y limpieza
3. Los datos procesados se guardarán en el directorio `Clean_Data/`

## Nota

Los datos originales no están incluidos en el repositorio debido a su tamaño. Consulte la documentación del proyecto para obtener información sobre cómo acceder a las fuentes de datos.
